# Version History

## v0.1
Foundation for local learning resources and offline-first content.

## v0.2
Local peer discovery and network-aware resource exchange.

## v0.3
Direct peer-to-peer transport using WebRTC DataChannels, signaling, chunked file transfer and transfer integrity checks.

## v0.4
Content-addressed resources, manifests, resumable transfers, persistent local cache, resource discovery and store-and-forward foundations.
