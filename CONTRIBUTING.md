# Contributing to Peddle iLabs MeshNet

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Keep protocol changes documented.
4. Add tests for new transfer, cache, discovery, or manifest behavior where practical.
5. Do not commit secrets, private learner information, credentials, or production telemetry.
6. Clearly distinguish measured behavior from experimental or planned functionality.
7. Open a pull request with a concise description of the change and how it was tested.
